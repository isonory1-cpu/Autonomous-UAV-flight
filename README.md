# Autonomous-UAV-flight

Программа автономного полёта БПЛА на базе Python. Скрипт обеспечивает автоматическое управление беспилотным летательным аппаратом, выполнение полётного задания по заданным точкам и обработку телеметрии.

## Возможности
* **Автономное выполнение миссии**: полёт по заранее заданному маршруту из файла конфигурации.
* **Чтение полётных заданий**: загрузка координат и путевых точек из файла `points.txt`.
* **Управление в реальном времени**: автоматическая отправка навигационных команд на полётный контроллер БПЛА.
* **Приём и обработка телеметрии**: контроль высоты, скорости, текущих координат и состояния батареи в процессе полёта.
* **Безопасность**: автоматический возврат домой (RTL) или посадка при потере связи или критическом разряде батареи.

## Требования к окружению
* **Язык программирования**: Python 3.8 или новее.
* **Основные библиотеки**:
  * `dronekit` (или `pymavlink`) — для связи с полётным контроллером.
  * Библиотека GUI (например, `tkinter` или `PyQt5`) — для графического интерфейса.
* **Для тестирования и симуляции**:
  * [Mission Planner](https://ardupilot.org) (наземная станция управления).
  * Симулятор **SITL (Software In The Loop)** для безопасной отладки полётного кода без реального дрона.

## Состав проекта
* `drone.py` — основной скрипт программы, содержащий логику интерфейса и отправки MAVLink-команд.
* `points.txt` — конфигурационный файл с координатами путевых точек для автоматического полёта по маршруту.

## Инструкция по запуску (в режиме симуляции)
1. Установите Mission Planner, откройте его, выберете формат подключения UDP, ip 127.0.0.1 host 14550
1. Через cmd запустите симулятор **SITL**, подключив симулятор к своему компьютеру, командой ArduCopter.exe --model quad --home -35.363261,149.165230,584,353 --serial0 tcp:0.0.0.0:5760 --serial1 udpclient:127.0.0.1:14550
2. Убедитесь, что симулятор открыл порт для подключения (по умолчанию для TCP это `127.0.0.1:5760`).
3. Запустите данную панель управления:
   ```bash
   python drone.py
   ```
4. Введите строку связи `tcp:127.0.0.1:5760` в верхнем поле приложения и нажмите кнопку **«Подключить»**.
5. Задайте высоту, нажмите **«ВЗЛЕТ»** и управляйте полётом вручную или по файлу маршрута.
